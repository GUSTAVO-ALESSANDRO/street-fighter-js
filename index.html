INSTRUÇÕES DO JOGO

Sobre o Jogo

Este é um projeto inspirado no clássico Street Fighter com funcionalidades reduzidas. O objetivo é vencer 2 rounds para conquistar a vitória da partida.

Controles do Jogador 1 (PvP / PvC)

W
A S D F G
W Pular
A Mover para Esquerda
S Ajoelhar / Defender (1/3 dano)
D Mover para Direita
F Golpe Jab
G Chute Baixo

Controles do Jogador 2 (Apenas PvP)

↑
← ↓ → K L
↑ Pular
← Mover para Esquerda
↓ Ajoelhar / Defender (1/3 dano)
→ Mover para Direita
K Golpe Jab
L Chute Baixo

Personalização

No menu principal você pode alterar o personagem dos lutadores e selecionar o cenário de fundo da batalha.
